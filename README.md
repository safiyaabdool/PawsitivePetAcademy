# PawsitivePetAcademy
Pawsitive Pet Academy is a modern Android application designed to provide users with information about professional pet-care training programmes and assist them in calculating course fees.

The application was developed using Android Studio and Kotlin and provides a simple, accessible and visually polished user experience.
Features: Clean and simple UI, Error handling.

Technologies used: Kotlin, Android Studio, XML, GitHub.

Installation: Clone the repository, open in Android Studio, Run the app.

GitHub Usage: GitHub was used for version control, allowing tracking of changes and maintaining a history of development.
